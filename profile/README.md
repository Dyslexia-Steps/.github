# Dyslexia Steps

[Dyslexia Steps](https://dyslexiasteps.com) is a free reading-skills site for parents and teachers of children aged 5 to 12: a free
screening test that runs in the browser, daily reading practice and printable word lists, in six languages. The screening test is a
screening, not a diagnosis; only a specialist can diagnose dyslexia.

## Open word lists
38 English phonics and sight word lists (1,079 different words), placed from Pre-K to Grade 3. Each list shows why it sits at its grade:
Dolch's own grade levels (public domain), the Common Core Foundational Skills item that names the skill, or a typical sequence when no
standard names it. Plus 216 lists in German, Spanish, French, Dutch and Brazilian Portuguese.

- [Word lists by grade](https://dyslexiasteps.com/word-lists-by-grade): the lists, their sources, printable, with audio
- [`dyslexiasteps-data`](https://github.com/Dyslexia-Steps/dyslexiasteps-data): the lists as CSV and JSON ([npm](https://www.npmjs.com/package/dyslexiasteps-data)), CC BY 4.0
- [`dyslexiasteps-mcp`](https://github.com/Dyslexia-Steps/dyslexiasteps-mcp): an MCP server so Claude, ChatGPT, Codex, Cursor and other assistants can look up the lists ([npm](https://www.npmjs.com/package/dyslexiasteps-mcp)), read-only

## Honest limits
A grade is a typical guide, not a rule: programs and standards differ, and a placement is not an assessment of any child. The lists in
other languages follow each language's own reading curriculum and have no grade. Word lists are licensed CC BY 4.0 (credit Dyslexia
Steps and link the page); the Dolch words are public domain. Code is MIT.
